# Premium Restaurant & Cafe WordPress Theme

A visually stunning, performance-optimized WordPress theme crafted for restaurants, modern bistros, bakeries, bars, and coffee shops. This theme balances an elegant presentation of your culinary identity with powerful utilities for digital menus, table bookings, and smooth online food delivery management.

## 🍽️ Key Features

*   **Dynamic HTML Food Menus:** Say goodbye to slow, clunky PDF downloads. Beautiful, mobile-optimized menu grids with tabs, categories (Appetizers, Mains, Drinks), pricing, and allergen tags.
*   **Table Reservation Integration:** Ready-made layouts integrated with OpenTable, Booked, or default WordPress reservation forms to capture table bookings directly.
*   **WooCommerce Food Ordering System:** Seamless integration with WooCommerce for takeaways, local food delivery tracking, and customizable checkout add-ons (e.g., specific delivery times, ingredient swaps).
*   **Visual Storytelling & Galleries:** Gorgeous full-screen video backgrounds, parallax effects, and slider setups to showcase restaurant interiors, signature dishes, and atmosphere.
*   **Mobile-First Design:** Optimized for hungry users searching on their smartphones on the go.
*   **Elementor & Block Editor Ready:** Easily modify layout, fonts, and brand colors via drag-and-drop.

## 🛠️ Tech Stack & Requirements

*   **Core Platform:** WordPress 6.x+
*   **Backend:** PHP 7.4+ / MySQL 5.7+
*   **Frontend Architecture:** CSS3 (Flexbox/Grid), JavaScript (ES6), HTML5
*   **Page Builders Supported:** Elementor, Gutenberg (Block Editor)

## ⚙️ How to Install

1. Download the theme repository as a `.zip` file from GitHub.
2. Log in to your WordPress Admin Dashboard.
3. Head over to **Appearance > Themes > Add New > Upload Theme**.
4. Upload the zip file, hit **Install Now**, and click **Activate**.
5. The setup wizard will prompt you to install recommended plugins (WooCommerce, Contact Form 7, etc.) and offer a 1-click demo content import.
